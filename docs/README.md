# Documentation Index

This is the index for the documentation folder. From here you shall be able to
navigate along all piece of information there should be.

As mentioned in the [CONTRIBUTING.md](../CONTRIBUTING.md#document-your-work)
this folder contains overall details about this project; ADR, User Guides, etc.

## Pages

* [Docker](./Docker.md) - how to build and run the ToM Server as a Docker
  image, and how to configure it through the config and registration files.
* [Configuration](./Configuration.md) - full reference for every `.tomconfig`
  option: server, databases, email, LDAP, federation, features, telemetry, and
  more.
* [Development](./Development.md) - helper scripts and tinkering tips for
  developers.
* [Release](./Release.md) - the branch naming convention and the release
  process followed by this project.
